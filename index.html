How it works

A simple chat UI talks to a self-hosted MCP server over Streamable HTTP.

💬

1. You type

A chat message in plain language, like a voice assistant request.

🔌

2. MCP server

A Python MCP server on /mcp picks the right tool and runs it.

📊

3. You get the answer

The expense is saved to JSON, and summaries are calculated from the same data.

MCP tools

Two tools, exposed to any MCP-compatible client.

🧾

add_expense

Takes an amount, a category and a note, then saves the expense with today's date.

📈

monthly_summary

Returns this month's total and a category-wise breakdown, highest first.

Run it locally

The chat needs the MCP server running on your machine.

Install 
python -m venv .venv
.venv\Scripts\activate
pip install "mcp[cli]" streamlit
Start the MCP server 
python mcp_server/server.py
Start the chat UI (new terminal) 
streamlit run chat_app.py

Then open http://localhost:8501.
